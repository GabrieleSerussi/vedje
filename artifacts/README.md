# Artifacts

`paper_results.json` holds the numbers of the paper that the README quotes and the Colab notebook charts, copied as the paper prints them. They come from Tables 1b, 3, 4, 5, 6, 9 and 12, and from Figure 1 with the rows of Table 22. Each block names its table or figure in `source`, and `vedje.paper.load_results()` reads the file. The release contains no trained checkpoints and no extracted features.
